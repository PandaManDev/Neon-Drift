# Neon Drift

A lightweight, responsive browser arcade game built with plain HTML, CSS, and JavaScript.

## Run it
1. Extract the ZIP.
2. Open `index.html` in a modern browser.
3. To publish it, upload the folder to GitHub Pages, Netlify, Cloudflare Pages, or any static web host.

## Controls
- Desktop: A / D or Left / Right arrow keys. Space pauses.
- Mobile: drag across the game area or use the on-screen arrow buttons.
- Collect yellow cores for bonus points. Avoid the pink blocks.

Your best score is saved in the browser on that device.
